# Content Governance and Editorial Rules

## 1. Preserve source content

Imported historical content must remain as originally published except for technical markup cleanup that does not change meaning.

## 2. New editorial workflow

Recommended responsibilities:

- Contributor: drafts
- Author: drafts/own content
- Editor: quality/format/SEO review
- Administrator: publication/system oversight

The principal author may be granted direct publish rights.

## 3. Required pre-publication checks

- Title
- Category
- Article body
- Author
- Slug
- Meta description
- Featured/default image
- Alt text where image is meaningful
- Social preview
- Internal links where appropriate

## 4. Updates

When materially revising an already published article:

- preserve original published date
- store updated date
- store revision
- avoid changing slug unless absolutely necessary
- if slug changes, create redirect

## 5. Deletion

Prefer unpublish/archive or soft delete.

Deleting an indexed article should require explicit admin action and redirect decision.

## 6. Categories/tags

Avoid category explosion.

Categories should represent durable content sections.
Tags/topics can be more granular.

## 7. Featured content

Homepage/editorial featuring is independent from publication date.

Use explicit featured controls/weights, not manual database changes.
