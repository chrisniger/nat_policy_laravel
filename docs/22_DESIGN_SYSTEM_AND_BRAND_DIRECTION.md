# Design System and Brand Direction

## 1. Brand principle

The redesign should be a **premium evolution of the existing National Policy Dialogue identity**, not a rebrand.

Use the supplied/current logo as the definitive visual source.

Primary direction:

- Green-led palette
- White / off-white editorial surfaces
- Deep neutral text
- Premium restrained accent usage
- Strong typography and spacing
- Serious institutional/policy tone
- Avoid generic political-campaign aesthetics
- Avoid cluttered news-portal styling

## 2. Brand language

Available existing expressions:

- National Policy Dialogue
- “…the abode of Wisdom.”
- “Awakening the New Nigeria Consciousness.”

Use them purposefully, not repetitively.

## 3. Design tokens

Do not invent final hex colors until logo/source assets are available in the implementation workspace.

Define tokens such as:

```text
--brand-primary
--brand-primary-dark
--brand-primary-soft
--brand-accent
--surface
--surface-muted
--text-primary
--text-secondary
--border
--success
--warning
--danger
```

Then map exact values from the approved logo/design.

## 4. Typography

Select a high-quality editorial pairing:

- Display/headline serif or distinguished sans
- Highly readable body type
- Clear UI sans for controls if needed

Optimize loading and use legal/self-hosted or licensed webfont sources.

## 5. Article aesthetic

Long-form NPD content requires:

- Comfortable line length
- Generous line height
- Strong section hierarchy
- Distinct blockquotes
- Captions
- Pull quotes
- Tables with horizontal containment
- Mobile-safe embedded media

## 6. Component inventory

- Utility bar
- Main navbar
- Mobile menu
- Search overlay/page
- Hero
- Article card variants
- Category chip
- Author chip/card
- Newsletter form
- Dialogue CTA
- Membership CTA
- Gallery card
- Breadcrumbs
- Share controls
- Reading progress
- Pagination
- Footer
- Form fields
- Alerts/toasts
- Modal/dialog
- Skeleton/loading state where needed
- Empty/error state

## 7. Design quality bar

The result should resemble a credible international research/policy publication in polish, while remaining distinctly NPD.

Do not clone another organization’s copyrighted design or content.
