## Publish an article
1. Open Articles → New Article.
2. Enter title.
3. Add body.
4. Add short excerpt.
5. Select category.
6. Add tags/topics.
7. Select author.
8. Upload featured image or allow default thumbnail.
9. Open SEO panel and confirm title/meta/slug.
10. Preview.
11. Publish now or schedule.
